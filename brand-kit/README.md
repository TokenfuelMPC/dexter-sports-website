# Brand Kit — Dexter Sports Co.

Everything needed to keep the brand consistent and to rebuild or extend the site: logos, photography, video (original sources plus web-ready versions), the public deck, and documents.

**Start with [`brand-guide.html`](brand-guide.html).** Open it in any browser for colors, fonts, logo rules, imagery, and voice.

> This folder is **not** part of the live website. The site uses its own copies in `assets/`. Hosts don't need to publish `brand-kit/`; see `docs/WEBMASTER-GUIDE.md`.

| Folder | Contents |
|---|---|
| `logo/` | `dexter-mark.svg`, `dexter-mark-1024.png`, wordmark on dark and on light (`.svg` + `.png`). Shareable bundle: `dexter-logo-files.zip` |
| `photography/` | Kim's headshot as used on the site (960×1200), plus the original 400 px LinkedIn source it was cropped from (still shows the #OpenToWork ring; for reference only, **don't publish**) |
| `video/source/` | Original Pexels downloads, unedited (see [`video/README.md`](video/README.md) for IDs and license) |
| `video/web/` | Compressed versions used on the site, posters, and an unused alternate |
| `decks/` | `Dexter_Sports_Overview_PUBLIC.pptx`: the shareable overview deck. (The internal investor deck stays in `_strategy/`, which is private.) |
| `documents/` | *Before You Sign* NIL toolkit (PDF) |
| `social/` | Link-preview image (1200×630) used when the site is shared |
| `brand-guide.html` | The visual brand guide |
